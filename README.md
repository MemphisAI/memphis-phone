# Memphis on the phone

The phone side of Memphis: a home-screen web app that works offline and syncs a private book
repository through the GitHub API. This repository holds only the app's code. It holds no book
text and no key: on first open the app asks for the repository and a fine-grained GitHub key,
and keeps both on the phone only.

Built from the Memphis source by `tent/phone/build-site.js`; do not edit these files here.
