# Preview: the phone redesign

A preview of the redesign from the `redesign` branch, published here so it can be tried on the phone before it goes into Memphis's source (`tent/phone/build-site.js` on Alaric).
Open `…/memphis-phone/preview/` on the phone. It borrows the sign-in from the main app once and keeps its own copy of the book (IndexedDB `memphis-phone-preview`), so the main app is untouched.
If a build from Alaric wipes this folder, publish it again from the `redesign` branch. Delete it once the redesign is ported.
